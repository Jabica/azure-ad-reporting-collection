A collection of three PowerShell scripts to export Azure AD users, detect duplicates by email prefix across domains, and find similar display names using Levenshtein distance.

## Overview

These scripts automate common Azure AD reporting tasks:

- **Export-Users.ps1**  
  Connects to Microsoft Graph and exports every user’s DisplayName, UserPrincipalName and email “prefix” to a CSV.

- **Exportar Users na Azure com 2 e-mails.ps1**  
  Finds users whose email prefix (the part before “@”) appears in more than one domain and exports a CSV of those duplicates.

- **Validate-Similarity.ps1**  
  Reads a CSV of users, computes Levenshtein similarity on Prefix and DisplayName, and reports pairs above a configurable threshold.

---

## Scripts

### Validate-Similarity.ps1

- **Purpose**: Detect pairs of users whose DisplayName or email “prefix” are highly similar (Levenshtein-based).
- **Parameters**:
  - `-Threshold [int]`  
    Minimum similarity percentage (0–100) to flag a pair. Default: `85`.
- **Input**:  
  `users_list.csv` (must contain `DisplayName`, `UserPrincipalName`, `Prefixo`).
- **Output**:  
  `usuarios_similares.csv` with columns  
  `Nome1`, `Email1`, `Nome2`, `Email2`, `Similaridade_Prefixo`, `Similaridade_Nome`.

### Export-Users.ps1

- **Purpose**: Connect to Microsoft Graph and export all Azure AD users.
- **Behavior**:
  1. Authenticates via `Connect-MgGraph -Scopes "User.Read.All"`.
  2. Calls `Get-MgUser -All` to retrieve every user.
  3. Builds a CSV with `DisplayName`, `UserPrincipalName`, and lowercase email prefix.
- **Output**:  
  `users_list.csv` (UTF-8, no type information).

### Exportar Users na Azure com 2 e-mails.ps1

- **Purpose**: Identify email prefixes duplicated across multiple domains.
- **Behavior**:
  1. Ensures Graph auth (`Connect-MgGraph -Scopes "User.Read.All"`).
  2. Gets all UPNs via `Get-MgUser -All | Select UserPrincipalName`.
  3. Groups by prefix (before ‘@’, lowercase).
  4. Flags groups where more than one unique domain exists.
  5. Exports results to CSV and prints each duplicate group.
- **Output**:  
  `usuarios_com_mesmo_nome_dominios_diferentes.csv` with columns  
  `Prefixo`, `Dominios`, `Enderecos`.

---

## Requirements

- **PowerShell** 5.1 or PowerShell Core (Windows, macOS, Linux)  
- **Microsoft.Graph** module installed  
  ```powershell
  Install-Module Microsoft.Graph -Scope CurrentUser
  ```
- **Permissions**: Your signed-in account must have the **User.Read.All** scope on Microsoft Graph.
- **Input files** (for Validate-Similarity):  
  - `users_list.csv` generated by **Export-Users.ps1**.

## Usage

> **Tip**: Always run these in the same folder so that CSV paths resolve locally.

### 1. Export-Users.ps1

```powershell
# Authenticate (if not already signed in)
Connect-MgGraph -Scopes "User.Read.All"

# Run the export
.\Export-Users.ps1

# → Generates .\users_list.csv
```

### 2. Exportar Users na Azure com 2 e-mails.ps1

```powershell
# Authenticate (if not already signed in)
Connect-MgGraph -Scopes "User.Read.All"

# Detect duplicate prefixes across domains
.\Exportar Users na Azure com 2 e-mails.ps1

# → Generates .\usuarios_com_mesmo_nome_dominios_diferentes.csv
```

### 3. Validate-Similarity.ps1

```powershell
# Ensure you have users_list.csv in this folder
# Run with default threshold (85%)
.\Validate-Similarity.ps1

# Or specify a different threshold, e.g. 90%
.\Validate-Similarity.ps1 -Threshold 90

# → Generates .\usuarios_similares.csv
```

## Visão Geral

Estes scripts automatizam tarefas comuns no Azure AD:

- **Export-Users.ps1**  
  Conecta ao Microsoft Graph e exporta o DisplayName, UserPrincipalName e prefixo de e-mail de cada usuário.

- **Exportar Users na Azure com 2 e-mails.ps1**  
  Identifica usuários cujo prefixo de e-mail (parte antes do “@”) aparece em mais de um domínio e gera um CSV.

- **Validate-Similarity.ps1**  
  Lê um CSV de usuários, calcula similaridade de Levenshtein em Prefixo e DisplayName e reporta pares acima de um limiar configurável.

---

## Scripts

### Validate-Similarity.ps1

- **Propósito**: Detectar pares de usuários com DisplayName ou prefixo de e-mail muito semelhantes.
- **Parâmetros**:
  - `-Threshold [int]`  
    Percentual mínimo de similaridade (0–100) para sinalizar o par. Padrão: `85`.
- **Entrada**:  
  `users_list.csv` (colunas `DisplayName`, `UserPrincipalName`, `Prefixo`).
- **Saída**:  
  `usuarios_similares.csv` com colunas  
  `Nome1`, `Email1`, `Nome2`, `Email2`, `Similaridade_Prefixo`, `Similaridade_Nome`.

### Export-Users.ps1

- **Propósito**: Conectar ao Microsoft Graph e exportar todos os usuários do Azure AD.
- **Fluxo**:
  1. `Connect-MgGraph -Scopes "User.Read.All"` para autenticar.  
  2. `Get-MgUser -All` para obter todos os usuários.  
  3. Gera um CSV com `DisplayName`, `UserPrincipalName` e prefixo em minúsculas.
- **Saída**:  
  `users_list.csv` (UTF-8, sem tipo).

### Exportar Users na Azure com 2 e-mails.ps1

- **Propósito**: Identificar prefixos de e-mail duplicados em múltiplos domínios.
- **Fluxo**:
  1. `Connect-MgGraph -Scopes "User.Read.All"` (autenticação).  
  2. `Get-MgUser -All | Select UserPrincipalName` para listar UPNs.  
  3. Agrupa por prefixo (antes do “@”, em minúsculas).  
  4. Filtra grupos com mais de um domínio.  
  5. Exporta CSV e imprime cada caso no console.
- **Saída**:  
  `usuarios_com_mesmo_nome_dominios_diferentes.csv` com colunas  
  `Prefixo`, `Dominios`, `Enderecos`.

- **Permissões**: Conta com escopo **User.Read.All** no Microsoft Graph.  
- **Arquivos de entrada** (para Validate-Similarity):  
  - `users_list.csv` gerado pelo **Export-Users.ps1**.


```powershell

.\Validate-Similarity.ps1 -Threshold 90

```
